The visitor decides how the site looks.

Shakuf is a free, open-source accessibility widget for Hebrew websites. It adds one button through which each visitor adjusts the display for themselves: text size, contrast, spacing, motion. No server, no account, no data collection. One script tag to install.

The rest of this site is in Hebrew. The panel on this page is in English, because the widget follows the page language.

What it changes

Nothing, until the visitor asks. Every adjustment is the visitor's choice, is stored only in their browser, and is undone with one click. Larger text in four steps, line, letter and word spacing, a readable font, high contrast, inverted colours, greyscale, link highlighting, hidden images, stopped animations, a visible keyboard focus, a large cursor, a reading ruler, and lists of the page's headings, landmarks and links. The panel also shows the site's accessibility statement and coordinator details, when the site owner provides them.

It touches display only. It does not change ARIA, page structure or the visitor's screen reader, which is where tools of this kind usually do harm.

What it does not do

This tool adjusts display only and does not ensure conformance with SI 5568 or substitute for making the site accessible.

Israeli regulation 35 requires the website itself to meet SI 5568 (WCAG 2.1 AA). That, a published accessibility statement, a named accessibility coordinator where the duty applies, a channel for accessibility complaints and review by a certified accessibility surveyor all remain the site owner's responsibility. Shakuf helps with the one thing it can: letting the visitor adapt the display. The full disclaimer (Hebrew).

Privacy

The widget makes no network requests and sets no cookies. Preferences live in the visitor's localStorage on your domain and go nowhere. A preference such as "high contrast" can be read as an inference about disability, so there is no server to receive it. If you load the script from jsDelivr, the visitor's browser fetches the file from them; self-hosting removes that third party.

Install

Paste this before </body>:

html · before </body>
<script src="https://cdn.jsdelivr.net/npm/@shakuf-widget/widget" defer></script>

Add data-statement-url, data-coordinator-name, data-coordinator-phone and data-coordinator-email so the panel shows your site's accessibility details. Set data-lang="en" on an English page, or leave it to follow <html lang>. Platform instructions, an npm path and the full attribute reference are in the setup guide (Hebrew); the package README on npm (external link) is in English.
