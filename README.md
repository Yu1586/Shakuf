# תוסף נגישות לאתרים ישראליים

כלי עזר בעברית שמאפשר למבקרים באתר להתאים לעצמם את התצוגה: גודל טקסט, ניגודיות,
מרווחים, עצירת אנימציות, סרגל קריאה ועוד.

> ### מה הכלי הזה לא עושה
>
> **הוא אינו הופך אתר לנגיש ואינו מבטיח עמידה בת״י 5568 או בכל דין אחר.**
>
> הנגשה מלאה מחייבת תיקונים בקוד ובתוכן האתר עצמו, פרסום הצהרת נגישות, מינוי
> רכז נגישות ובדיקה של מורשה נגישות. האחריות לעמידה בדין חלה על בעל האתר בלבד.
>
> ההסבר המלא, כולל מה אסור לומר על הכלי בפרסום: **[DISCLAIMER.md](DISCLAIMER.md)**.

## התקנה

תג script אחד, בכל סוג אתר — WordPress, Wix, Shopify, HTML רגיל, או כל מערכת אחרת:

```html
<script src="https://cdn.jsdelivr.net/npm/@a11y-il/widget" defer></script>
```

### הגדרות

כל ההגדרות אופציונליות ונקראות מתג ה-script עצמו. אין מפתח רישוי ואין הרשמה.

```html
<script src="https://cdn.jsdelivr.net/npm/@a11y-il/widget"
        data-position="bottom-right"
        data-offset="20"
        data-accent="#0b5fff"
        data-statement-url="/accessibility"
        data-coordinator-name="דנה לוי"
        data-coordinator-phone="03-0000000"
        data-coordinator-email="access@example.co.il"
        defer></script>
```

| מאפיין | ברירת מחדל | תיאור |
|---|---|---|
| `data-position` | `bottom-right` | `bottom-right` \| `bottom-left` \| `top-right` \| `top-left` |
| `data-offset` | `20` | מרחק בפיקסלים משולי המסך |
| `data-accent` | `#0b5fff` | צבע ראשי בפורמט hex. צבע הטקסט נבחר אוטומטית לפי ניגודיות |
| `data-statement-url` | — | קישור להצהרת הנגישות של האתר |
| `data-coordinator-name` | — | שם רכז הנגישות |
| `data-coordinator-phone` | — | טלפון רכז הנגישות |
| `data-coordinator-email` | — | דוא״ל רכז הנגישות |

אם לא הוגדרו פרטי הצהרת נגישות ורכז נגישות, החלונית מציגה למבקר הודעה שהאתר
חסר אותם — משום שהדין הישראלי מחייב את שניהם.

### דרך npm

```bash
npm install @a11y-il/widget
```

```ts
import { mount } from '@a11y-il/widget';

mount({ position: 'bottom-left', statementUrl: '/accessibility' });
```

## מה הכלי מציע למבקר

**טקסט** — גודל טקסט (4 רמות) · מרווח שורות · מרווח אותיות · מרווח מילים ·
גופן קריא · ביטול יישור דו-צדדי

**צבע וניגודיות** — ניגודיות גבוהה · צבעים הפוכים · גווני אפור · רוויית צבע ·
הדגשת קישורים · הסתרת תמונות

**תנועה ומיקוד** — עצירת אנימציות וניגון אוטומטי · הדגשת מיקוד מקלדת ·
סמן עכבר גדול · סרגל קריאה

**ניווט** — רשימת כותרות · רשימת אזורים · רשימת קישורים, עם מעבר ממוקד לכל פריט

**נגישות באתר** — קישור להצהרת הנגישות ופרטי רכז הנגישות

## עקרונות התכנון

הכללים האלה הם החלטות מכוונות, לא מקריות:

- **כל פעולה יזומה על ידי המבקר.** דבר לא משתנה בטעינת העמוד מלבד הצגת הכפתור.
- **הכלי לא נוגע ב-ARIA, ב-roles ובסמנטיקה של האתר.** הוא משנה תצוגה בלבד.
  שכתוב אוטומטי של ARIA הוא הסיבה המרכזית לכך שכלים מסוג זה פוגעים במשתמשי
  טכנולוגיה מסייעת.
- **הכלי לא מתערב בקורא המסך של המבקר** ואינו מציע ״מצב עיוור״.
- **הכל הפיך בלחיצה אחת.**
- **אין שרת, אין חשבון, אין מפתח, אין איסוף מידע.** ההעדפות נשמרות ב-`localStorage`
  בדפדפן של המבקר, על הדומיין של האתר, ולא נשלחות לשום מקום. העדפה כמו ״ניגודיות
  גבוהה״ עשויה להעיד על מוגבלות, ולכן היא לא צריכה להגיע לשום שרת.
- **הכלי עצמו עומד ב-WCAG 2.1 AA** — ניווט מקלדת מלא, ניהול מיקוד, הכרזות
  לקורא מסך בעברית, יעדי לחיצה של 44px, ניגודיות מינימלית 5.1:1.

## פיתוח

```bash
npm install
npm run build
```

הרצת דף הבדיקה המקומי:

```bash
npx serve -l 4321 .
```

ואז לפתוח `http://localhost:4321/demo/`.

| פקודה | פעולה |
|---|---|
| `npm run build` | בונה את `dist/a11y.js` (script tag) ואת `dist/index.js` (npm) |
| `npm run typecheck` | בדיקת טיפוסים |

גודל נוכחי: **12.6KB gzipped**, ללא תלויות בזמן ריצה.
